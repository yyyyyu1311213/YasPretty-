# Yas Pretty Brand Assets

This folder contains the first original brand asset set derived from the project visual guidelines.

## Included

- `logo/`: dark and light wordmarks plus the YP monogram in SVG and transparent PNG.
- `doodles/`: 16 independent cosmetic line illustrations in SVG and transparent 1000 x 1000 PNG.
- `doodles/reference-cutouts/`: 46 transparent PNG cutouts extracted from the four user-provided reference sheets; the existing `doodles/` files remain unchanged for compatibility.
- `hero/`: desktop and mobile hero compositions with clear copy space, supplied as SVG, RGBA PNG and JPG.
- `social/`: a 1200 x 630 share cover in SVG and PNG.
- `asset-manifest.json`: creation, provenance, palette, dimensions and status records.
- `asset-contact-sheet.png`: review sheet for the current doodle, logo and hero set.
- `asset-export-validation.json`: dimensions and alpha-channel checks from the latest deterministic export.

## Palette

- Warm ivory `#F8F3F0`
- Mist nude pink `#EAD4D3`
- Dusty rose `#D6B9B7`
- Milk coffee brown `#B59A8C`
- Deep cocoa `#5B4A43`

## Usage Notes

- Prefer SVG for interface use and animation.
- Use the raster exports for sharing, documents and environments without SVG support.
- Hero assets contain no title, button or promotional copy. Place live HTML text in the clear area.
- The wordmark SVG uses a system serif stack and does not redistribute a font file.
- Product cutouts are intentionally excluded. They must be made from individually verified real product images and retain source and authorization records.
- No generic editorial imagery is included. Add a new image only when it has a specific page role and approved visual direction.

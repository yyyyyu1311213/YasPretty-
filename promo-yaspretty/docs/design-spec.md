# YasPretty 宣传片设计规范

## 产品简报

- 产品：YasPretty 小Y，个性化妆容规划与可信产品决策平台。
- 目标：为参赛展示制作一支简洁、高级、全面的 16:9 宣传片，真实呈现网站中的微交互与可信边界。
- 核心受众：美妆新手、有明确条件的消费者、需要完整妆容步骤的用户。
- 叙事命题：用户缺少的不是更多推荐，而是一个把条件说清楚、把来源摆出来、把理由讲明白，并允许随时改条件的决策过程。
- 真实性边界：只展示当前真实可运行的 3D 化妆桌、35 款受控产品资料、8 个品类、结构化妆容方案、产品核验信息、小Y、本地收藏与降级提示。照片分析、账号体系、跨设备同步和公网部署不入片。
- 数据边界：所有画面来自本地公开演示状态；不使用真实用户照片、对话、画像或密钥。产品图片继续保留“来源已披露、授权待核验”的项目状态。

## 需求到执行决策

| 用户要求 | 执行决定 |
|---|---|
| 简洁 | 每镜只讲一个动作；文案一屏不超过两层；用停留和构图建立高级感。 |
| 高级 | 复用产品纸张、玫瑰、暖墨与编辑部排版；低过冲、慢推镜、少量高质量光效。 |
| 全面展示 | 覆盖品牌开幕、3D 化妆桌、产品库、筛选、详情、核验、方案、小Y、收藏和降级边界。 |
| 网站小巧思 | 放大编辑示例标签、来源状态、本地规则降级、收藏计数、照片非必填、来源可追溯等细节。 |
| 加入 slogan | 开场保留 “You are so pretty”；收尾使用“你的样子，不需要被改写。”。 |

## 视觉与动效 Tokens

- 方向：`Rose Editorial Archive`，精致高端预设，能量偏低、调性温柔但不幼态。
- 色板：纸底 `#fff5ee`、表面 `#fffdfb`、暖墨 `#4a3738`、玫瑰 `#c9828d`、深玫瑰 `#965261`、鼠尾草 `#758d82`。
- 字体：中文标题使用 Georgia / Noto Serif SC / Songti SC；正文使用 Noto Sans SC / Microsoft YaHei；标签使用 DM Mono / ui-monospace。
- 运动：主入场约 42–48f，`cubic-bezier(.4,0,.6,1)`；页面推镜约 60–90f；过冲不超过 1.02；不使用 squash。
- 光感：暖白纸面、单次玫瑰聚光、轻微颗粒；不使用群发 glint、霓虹或大面积冷色。
- Styleframe：不单独重造视觉稿。产品已有严格且完整的品牌视觉，最终素材直接采用 2× 真实页面截图；此决定避免宣传片另造一套“皮肤”。

## 镜头映射

| 功能 | 镜头卡 / 变体 | 采用方式 |
|---|---|---|
| 品牌开幕 | `blur-slide` + 真实品牌开幕 | 保留逐词收敛与长停留，直接使用真实页面。 |
| 3D 化妆桌 | `spotlight-hero-card` | 用单主角、聚光、慢推与落定呼吸；主角改为真实 3D 妆台。 |
| 条件筛选 | `type-and-filter` | 输入条件后筛选结果收敛；不伪造产品事实。 |
| 产品核验详情 | `row-embed` | 详情抽屉按基础信息、色号、分项评价、来源逐段揭示。 |
| 结构化方案 | `document-typewriter-reveal` | 方案步骤按行显现，保留生成后可阅读的停留。 |
| 品牌收尾 | `outro-group-photo-launch` | 页面元素围拢品牌字标；字标落定后保持 1 秒以上真静止。 |

## 分镜与帧级时间线

| # | 时间 | 镜头 | 关键动效 |
|---|---|---|---|
| 1 | 0–4.5s | 痛点：同样的自然色，为什么会差两个色阶？ | 编辑字卡逐句收敛，三枚条件标签落定。 |
| 2 | 4.5–8.5s | YasPretty 品牌开幕 + You are so pretty | 真实开幕页缓慢推近，品牌保持呼吸。 |
| 3 | 8.5–14s | 3D 化妆桌与 8 品类 | 聚光由妆台中心展开，页面轻微 2.5D 斜推。 |
| 4 | 14–17s | 35 款、8 品类、来源可追溯 | 三个数字依次落定，留出阅读停顿。 |
| 5 | 17–22.5s | 产品库、筛选、搜索 | 条件逐字输入，页面推近结果区，筛选标签依次点亮。 |
| 6 | 22.5–27.5s | 产品详情与核验边界 | 详情抽屉从右侧进入，四条核验信息分段揭示。 |
| 7 | 27.5–33s | 小Y条件采集 | 肤质、预算、场景、妆效四枚条件落位，强调照片非必填。 |
| 8 | 33–39s | 结构化七步妆容方案 | 从表单推至计划结果，步骤、依据、注意事项逐段显现。 |
| 9 | 39–42.5s | 收藏与本地掌控 | 收藏清单定格，突出本地保存、可清除、无强制注册。 |
| 10 | 42.5–49.5s | 功能全家福 + slogan | 页面卡片围拢；YasPretty 与“你的样子，不需要被改写。”落定。 |

验收帧：每镜头分别检查入场中段、动作峰值、落定后帧；全片检查 1920×1080、30fps、49.5s。

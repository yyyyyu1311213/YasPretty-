# YasPretty 产品图片采集清单

> 产品名称、价格、色号、产地、体验字段和公开门禁必须同时遵守 [产品资料采集任务单](./product-data-collection-brief.md)。本文件只补充图片来源、文件落位和图片验收；找到图片不等于产品资料已核验，也不等于获得公开再利用授权。

短期图片规则：每款产品先收集 1 张正面封面图，优先使用品牌官网产品页、官方旗舰店或品牌媒体素材。不要将搜索结果页图片直接热链到网站；下载后的图片必须绑定原始来源页面、权利人、采集日期和授权状态。

实际文件位置：`public/products/<产品 id>/cover.webp`。图片统一使用 WebP，长边不超过 1200 px。原始采集文件和 `来源清单.csv` 保留在 `YasPretty产品图片/YasPretty产品/`，不移动、不覆盖，作为来源证据。

2026-10-29 阶段 3 图片接入补充已完成 35 张封面落位：23 张来源于品牌官网页面、11 张来源于零售商页面、1 张来源于媒体页面。35 张图片授权状态均为 `pending`；根据项目负责人确认的参赛策略，允许在逐张来源可追溯、页面显示授权待核验状态和联系删除入口的前提下用于公开参赛版本，但不得表述为已经取得授权。

## 图片验收

- 一款产品至少一张正面、无手持和无文字遮挡的产品图。
- 优先使用纯色或透明背景，画幅以 1:1 为主。
- 保存来源页面和授权状态；授权待核验的图片按 `AGENTS.md` 6.4 节公开策略展示，不得标记为已授权。
- 文件落位后，统一命名为 `cover.webp`，例如：`public/products/dior-forever-skin-glow/cover.webp`。
- 页面统一显示：“图片来源于网络，版权归原权利人所有。如权利人认为使用不当，请通过页面联系入口联系我们，我们将在核实后及时删除或替换。”

# YasPretty 暖玫瑰全局色彩基线

记录日期：2026-11-04（北京时间）

本基线来自当前已经落地并通过视觉复核的品牌开幕、3D 花瓣妆台、页眉字标和页面色阶。后续页面、动效和素材优先复用这些 Token；与旧色表冲突时，以本记录和《Yas_Pretty 视觉设计素材》最新章节为准，同时保留旧记录用于追溯。

| Token | HEX | 主要用途 |
| --- | --- | --- |
| Warm Paper | `#FFF9F5` | 全站页面底色 |
| Surface | `#FFFEFC` | 表单、详情、浮层 |
| Opening Blush | `#FFD8E4` | 品牌开幕主背景 |
| Yas Rose | `#D9577D` | 开幕标题 Yas |
| Pretty Rose | `#EC7897` | 开幕标题 Pretty |
| Brand Rose | `#C95E7B` | 页眉页脚 YasPretty 字标 |
| Rose Accent | `#E48AA1` | 标签、状态、局部强调 |
| Rose Deep | `#B84267` | 主要按钮和选中态 |
| Peach Surface | `#FFE8E2` | 选中背景、柔和分区 |
| Champagne Gold | `#F0C879` | 3D 金属环、泵头、高光 |
| Pearl Mirror | `#FFF3F5` | 镜面、柔雾、珍珠亮面 |
| Ink | `#4F363A` | 标题、重要正文 |
| Muted | `#8C696C` | 说明、元信息 |
| Line | `#F3D7D5` | 分隔线、边框 |

建议比例：暖粉白与浅表面色约 65%，柔和粉色层约 20%，玫瑰强调色约 8%，香槟金约 4%，深色文字与结构线约 3%。比例用于控制整体观感，不要求逐像素计算。

全局方向是高明度、温暖、粉嫩且克制。仙气来自珠光暖白背景、蜜桃柔粉、透明层、细小星芒、柔雾和香槟金高光；质感来自深浅层级、留白、细线和受控对比。禁止大面积灰紫、浑浊米灰、荧光粉、紫蓝粉渐变和单一粉色覆盖所有组件。

产品图片不得因品牌色而被改色；界面综合色调也不得暗示未核验的色号、质地或功效。星星、花瓣、薄雾和流光只用于局部氛围，不能遮挡任务入口、来源、限制或隐私说明。

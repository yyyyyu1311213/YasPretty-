## 范围与来源

- 目标是在主站首页提供真实可操作的 3D 妆台，不替代小Y妆容方案、产品库或现有产品事实。
- 项目负责人提供的两张粉色手绘图片只作为桌体构图、八个品类和粉金配色参考。原图没有复制到 `public/` 或构建产物，不作为产品图片；其创作来源与再利用授权未核验。
- 桌体、镜子和八件妆具全部由 Three.js 基础几何体与本地材质实时生成，不使用 GLB、远程贴图、外部图片或具体品牌包装。`textureMap` 当前固定为 `null`，只保留未来本地资产接口。
- 运行依赖为 Three.js、React Three Fiber、Drei、GSAP 和 Framer Motion。前三者及 Framer Motion 为 MIT；GSAP 为 Standard "no charge" license。Drei 会带来较大的浏览器分块，当前 3D 分块约 1.18 MB（gzip 约 334 KB）。

## 实现与用户入口

- `src/components/MakeupTable3D.jsx`：主站入口、Framer Motion UI、WebGL 能力检查和错误边界。
- `src/components/makeup-table-3d/Scene.jsx`：Canvas、灯光、阴影、响应式相机和 OrbitControls。
- `DressingTable.jsx`、`CosmeticItem.jsx`、`ParticleBurst.jsx`：桌体、八类妆具、GSAP 花瓣炸开和粒子光点。
- `cosmetics.js`：稳定 ID、品类、桌面/炸开位置、材质色和贴图预留字段。
- 首页点击粉底液或底部“粉底液”按钮可展开/收拢；空白处和右上角复位按钮可收拢；其他品类进入现有产品库筛选。
- 交互修正：3D 妆具模型和底部品类栏现在统一只负责进入对应产品品类；粉底液模型点击进入真实粉底液产品库，不再触发展开动画。花瓣展开/收拢改由独立闪光按钮控制，避免品类导航与展示动效冲突。
- 视觉细化：妆具增加圆角瓶身、透明外壳、内芯、泵头、粉盘、盖体、金属环和简化品牌标记；桌面、抽屉与镜架使用圆角几何体，减少直接基础几何体的生硬感。右上角闪光按钮旁增加虚线箭头提示“点击会有奇妙效果”。Canvas 使用透明清屏叠加页面渐层，保留地面阴影与雾作为后续花瓣、薄雾和流光动效的统一承载层。
- 暖粉视觉修正：全局纸张、边线、主色、页眉/页脚 YasPretty SVG 字标、3D 灯光/雾/镜面/桌体/妆具统一提亮；开幕增加小星芒、闪粒和高光，主字标改为明亮玫瑰粉铜。提示轨迹按负责人红笔路径调整为“文字起点 -> 小回旋 -> 向右上扬 -> 指向闪光按钮”，不再靠近复位按钮。

## 回退与问题定位

- 旧 `src/components/MakeupTable.jsx` 和 `MakeupTable.css` 保持不变。WebGL 不可用或 3D React 树渲染失败时，`MakeupTable3D` 自动返回旧版可操作品类桌。
- 主站切换点只有 `src/App.jsx` 中懒加载 `MakeupTable3D` 的入口。需要人工回退时可恢复为旧 `MakeupTable` 导入，不需修改产品数据或 API。
- 项目负责人已于 2026-11-04 授权同步 GitHub；实现随检查点 `86f61df4433bd48dd97b7890cf150cca0c8275c6` 提交，远端同步前状态由 `codex/rollback-pre-sync-20261104` 保存。未创建阶段 tag。

## 边界与风险

- 几何妆具只代表品类，不代表具体商品外观、规格、颜色或功效。
- 3D 不读取照片、不调用外部服务、不写入本地存储，也不记录视角。
- 低性能设备可能出现首屏 3D 分块加载延迟；当前通过按需加载、DPR 上限和 2D 回退控制风险，尚未完成广泛真机性能测试。
- `npm audit` 当前报告 3 个中等级漏洞，来源是既有 `@fastify/static -> glob/minimatch` 依赖链。自动修复要求强制安装存在破坏性变化的 `@fastify/static@6.12.0`，本次没有越权执行；需在独立后端兼容性任务中评估升级方案。
- 当前 R3F 运行时会输出上游 `THREE.Clock` 弃用警告；没有未处理错误，交互与渲染不受影响。软阴影类型弃用警告已通过显式基础阴影配置消除，上游时钟警告仍需随兼容版本升级处理。
- 本条是阶段 5 体验增量，不代表阶段 4 视觉分析或阶段 5 公开交付整体完成。

# 阶段 0：仓库安全与基线

记录日期：2026-10-28（北京时间）

## 范围和结论

本阶段只整理仓库安全与事实基线，不改变用户界面或产品流程。仓库可以本地运行并完成 Vite 生产构建，但目前仍是参赛开发版本，不满足公开部署、数据验收或完整参赛作品验收。

阶段 0 完成项：

- 建立 `.gitignore`、`.env.example` 和 README 基础版。
- 扫描密钥、隐私数据、临时目录、构建产物和素材风险。
- 移除旧版 HTML 中的一枚硬编码智谱凭据，未在报告中记录凭据内容。
- 记录当前功能、产品数据结构和构建基线。
- 保持 React 页面、样式、产品数据和服务端行为不变。

- Git：仓库尚无正式提交；扫描时所有项目文件均为未跟踪状态。
- 运行时：Node.js `v24.18.0`，npm `11.16.0`。
- 技术栈：React、Vite、Lucide React、Node.js 裸 `http` 服务。
- 产品数据：31 条；粉底液 22、气垫 3、遮瑕 3、散粉 3；稳定 ID 无重复。
- 前端入口：`http://127.0.0.1:5174/`。

实际可见功能包括首页、产品库、筛选与排序、产品详情、肤质指南、收藏，以及集成的小Y页面。小Y当前提供本地规则推荐、天气查询、智谱对话和联网搜索的旧代理路径。照片分析、完整妆容方案、正式账户与生产部署均不存在。

## 数据真实性基线

旧版页面所需字段检查通过：31 条产品均包含当前页面使用的 ID、品牌、名称、类别、价格、图片、肤质、妆效、遮瑕、持妆、氧化、评分、色号、场景、编辑指标、优点和注意事项字段。

这不等于目标产品 schema 验收通过。当前覆盖情况：

| 目标字段 | 已填写产品数 | 状态 |
| --- | ---: | --- |
| `priceVerifiedAt` | 0 / 31 | 待核验 |
| `imageSource` | 0 / 31 | 待核验 |
| `informationSources` | 0 / 31 | 待核验 |
| `verificationStatus` | 0 / 31 | 待建立 |

因此当前 31 条产品的价格、产地、色号、产品描述及其他外部事实均不能宣称已完成来源核验。`rating` 与 `metrics` 没有用户样本、统计方法或外部来源，应视为编辑示例维度，不能表述为真实用户评分或大规模统计。

## 图片与知识产权基线

- `public/product/` 中现有本地产品图片没有逐张来源、授权状态或授权证明，已从 Git 提交范围排除。
- `public/brand/` 中两张品牌 JPG 正被页面使用，但仓库中没有权属或制作来源证明；这不等于判定其未授权，但在证明补齐前同样排除 Git。
- 部分产品使用 Unsplash 通用美妆图片；这些图片不是对应商品实物图，不能据此证明商品外观。
- `docs/product-image-collection.md` 当前只提供搜索入口，不是来源台账或授权证明。
- 图片采集文档建议使用 `public/products/`，实际目录是 `public/product/`；建立正式素材台账时需要统一路径。
- 正式公开版本必须为每张图片记录原始页面、权利方、许可证或授权依据、采集时间和允许用途。状态不明确时只能用于内部草稿。

## UI-A 当前问题

1. 首页远程 Unsplash 背景与产品核心任务关联弱，且存在弱网与素材来源披露负担。
2. 首页“小Y对话”、搜索与快捷筛选同时争夺主层级，“创建我的妆容方案”不是明确主操作。
3. 缺少品牌开幕、跳过、单次播放和 `prefers-reduced-motion` 处理。
4. `styles.css` 与 `xiaoy.css` 大量直接使用色值、间距和时长，页面之间容易漂移。
5. 产品库、产品详情和品牌信任页后续仍需要分别完成 UI-C、UI-D 和 UI-E；本子阶段不提前调整其业务结构。
6. 移动筛选与详情抽屉已有关闭和 Escape 路径，但焦点管理、滚动锁定和完整响应式验收仍属于 UI-F。

## 视觉系统

本子阶段在 `src/styles.css` 建立 `--yp-*` token：暖纸色与白色作为主背景，深可可色作为主文字和主要动作，玫瑰色作为品牌强调，鼠尾草绿仅表示“已记录或成功”等正向状态。颜色不单独证明产品事实、图片授权或推荐适配。

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px。
- 圆角：普通控件 2px；胶囊仅用于状态。
- 动效：常规 120–180ms，页面 420ms，开幕总时长 2200ms。
- easing：`cubic-bezier(.2, .7, .2, 1)`。
- 减少动效：取消位移、缩放和旋转，只保留不超过 120ms 的淡入。

## 页面结构方向

- 首页：品牌信号 → 产品定位 → “创建我的妆容方案” → 产品搜索 → 编辑精选 → 方法说明。
- 产品库：搜索与筛选 → 结果数和排序 → 稳定比例产品网格 → 空结果/异常状态。
- 产品详情：产品视觉与适配摘要 → 核验状态和收藏 → 参数、注意事项、证据与来源。
- 品牌信任页：项目动机 → 推荐方法 → 产品核验 → 隐私边界 → 第三方披露 → 图片策略与删除入口。

## 2026-11-04 用户复核修正

用户反馈首版开幕过于像“字母从两侧飞入”，与参考站所借鉴的紧密、轻盈、梦境式节奏不一致。问题定位为首版左右最大 136px 的线性位移和缺少整体字群节奏。

本次仅调整开幕视觉轨迹：改为中心紧密字群、轻微错位与旋转、短暂呼吸散开后归位；不复制参考站代码、素材或具体轨迹，不改变 2200ms、跳过和减少动效边界。

## 2026-11-04 开幕试版预览

经项目负责人确认，开幕试版允许调用 `public/assets/doodles/reference-cutouts/` 中的散粉云与粒子点素材用于本地预览。试版同时使用原创 `powder-puff.svg`、`sparkle.svg`、`yaspretty-wordmark-light.svg` 和 `yaspretty-monogram.svg`。

参考图裁切素材的授权状态仍保持 `pending-user-provided-reference`，本次只作为可回退的设计预览，不把它们表述为已取得公开再利用授权。若进入正式公开版本，需要在素材审计中补充项目负责人授权和权利边界。

## 2026-11-04 全站品牌一致性复核

用户截图反馈 header、首页 Hero 与品牌文化页同时使用三套不同的 YasPretty 标识，且品牌页仍引用旧 `/brand/` JPG。已将三处收敛到 `public/assets/logo/` 的本地 wordmark/YP 单标：header 与 footer 使用 wordmark，Hero 改为品牌信息行，CultureView 使用 YP 单标信息块；未改导航、产品数据或业务入口。

## 2026-11-04 开幕预览第二轮

用户复核认为首版开幕偏压抑、字标不够醒目。按反馈将背景从深可可棕提亮为暖玫瑰棕，wordmark 宽度提高，开幕总时长调整为 2600ms，并增加 5 组外围 sparkle 闪烁点；中心仍保持散粉云、粒子和 YP 单标的层次，不改变 reduced-motion 和跳过入口。

## 2026-11-04 开幕预览第三轮

用户进一步反馈素材需要更集中、字标需要明显放大、白色粉扑遮挡字标、背景仍偏压抑。已移除粉扑元素，改为藕粉背景 `#E4C3C5`，将 wordmark 宽度上限提高到 760px，增加粒子密度、7 组 sparkle 和两片低透明度原创花瓣；开幕总时长调整为 3000ms。参考图散粉素材仍仅用于本地预览，授权状态保持待核验。

同日追加一句艺术字副标 `You are so pretty`，使用系统手写字体栈，不新增字体依赖；副标在主 wordmark 后延迟浮现，并在减少动效偏好下仅淡入。

同日按用户要求将开幕单色藕粉背景改为珠光粉预览：使用低对比粉白、淡玫瑰和轻香槟色 CSS 高光叠层，不新增图片或依赖，其他开幕素材与节奏保持不变以便比较。

用户继续反馈亮晶晶元素和标题辨识度不足。开幕预览增加 8 个细粒子 glint，并将开幕主字标改为系统高对比衬线字体栈与 CSS 手绘下划线；不新增字体依赖，header/footer 的正式 logo 资产保持不变。

用户复核认为标题颜色偏压抑。已将开幕字标与副标改为半透明玫瑰灰棕，并在字标左上及下划线右侧加入两个低密度 sparkle 陪衬；元素不覆盖文字笔画，减少动效时仅淡入。

用户进一步明确收尾节奏：不让整句持续闪烁，而是在开幕结束前让 `Pretty` 单词单独闪亮一次。已拆分 `Yas`/`Pretty` 字层，加入一次性 sparkle 高光（约 2.42s 触发，非循环）。

用户新增梦醒式收尾要求。自动结束阶段新增约 680ms 的雾散动画：背景色层、散粉云、粒子、花瓣、sparkle、glint、字标和副标依次失焦、上浮、放大并淡出，组件在动画结束后才卸载；“跳过”仍保持快速 120ms 退出，减少动效偏好不播放位移和模糊。

用户复核认为首版梦醒收尾不够丝滑。问题定位为父层与子层同时施加强模糊，造成突然糊化。已改为父层只做透明度渐隐，背景雾层使用低强度 blur/scale，文字延迟约 90ms 后再轻微失焦，caption 延迟约 120ms，并统一使用 `--yp-ease-dream` 平滑曲线。

用户进一步明确所有元素可以同步散开，不需要保留中间文字。已取消背景、字标和 caption 的错峰延迟，统一在同一帧进入 680ms 的 opacity、轻 blur、上浮和 scale 动画；文字与背景现在作为一个整体同时化雾离场。

参考站当前返回验证码挑战，无法直接读取运行时动画源码；未将验证码页作为设计依据。针对“不丝滑”反馈，退出动画进一步收敛为单一连续转场：取消逐元素 blur，只保留统一 760ms 的透明度、轻微上浮、缩放和雾幕扩散，全部视觉层同一时间启动。

用户提供 `<div class="fade-out">Fade Out</div>` 作为参考。开幕收尾现改为真正的统一 `fade-out`：整个开幕层作为一个整体在 760ms 内只做透明度淡出，不再叠加子元素位移、缩放或 blur；所有背景与文字同步离场。

用户要求延长淡出时间。纯 `fade-out` 从 760ms 调整为 1100ms，自动关闭时点随 `EXIT_MS` 前移，保证淡出完整结束后再卸载。

用户再次反馈淡出仓促，已将统一根层淡出延长至 1500ms，并将完整开幕总时长调整为 4000ms；自动关闭仍在淡出结束后卸载，跳过入口继续使用 120ms 快速退出。该调整不改变背景、文字或业务入口。

用户希望淡出前保留一个素材齐全的稳定画面，并将主标题再放大。当前总开幕调整为 5200ms、统一淡出为 1800ms，收尾前增加约 900ms 的完整画面停留；主标题桌面字号上限由 148px 提至 176px，360px 级移动端使用独立上限避免横向溢出。跳过与 reduced-motion 行为保持不变。

用户截图反馈首页 Hero 右侧器物轮廓突兀。已同步调整桌面与移动 Hero SVG：右侧器物主体略加宽、顶部缩短并圆润化，降低尖头长管感，使其与左侧粉底瓶和镜面线条保持同一套简洁比例。

用户反馈开幕右侧小花素材被 YP 圆章遮挡。已将右侧花瓣移到圆章右下侧并略微缩小，保留完整花梗和花瓣轮廓；左侧花瓣、字标和其他粒子层级不变。

## 2026-11-04 副标笔画文字动效适配

用户指定使用 React Bits `StrokeText` 为开幕副标 `You are so pretty` 增加笔画绘制和填充擦入效果。React Bits 源码依赖 GSAP/ScrollTrigger，而本仓库没有该依赖；为避免未经确认的新增包和弱网负担，新增 `src/components/StrokeText.jsx` 与 `StrokeText.css`，保留其 SVG 分层、文字参数和 mount/hover/view 触发语义，使用 CSS 动画与 `prefers-reduced-motion` 降级实现。
